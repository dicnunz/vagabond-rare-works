# Vagabond Rare Works

An unofficial one-file archive of scarce *Vagabond* lottery posters, *Last Manga Exhibition* editions, and surviving promotional material, organized around physical-object records rather than a general image collection.

## Open

No installation or build step is required.

1. [Download the repository as a ZIP](https://github.com/dicnunz/vagabond-rare-works/archive/refs/heads/main.zip).
2. Open the downloaded ZIP.
3. Double-click `index.html`.

The gallery needs an internet connection because archival images are loaded from their source hosts.

## Archive

The route contains 26 physical objects, including entrant-lottery B3 posters, non-sale promotional material, FLOWER web-shop B1 prints, and exhibition ephemera. The site preserves object-level distinctions such as documented folds, dimensions, distribution method, and surviving provenance evidence.

`Tools` changes how the current object is studied rather than providing alternate gallery layouts: isolate, loupe, raking light, fold reconstruction, real-millimetre measurement, physical scale, comparison, provenance, private notes, a movable hanging wall, and a pan-and-zoom archive atlas.

Keyboard shortcuts are shown inside the site. Notes and wall arrangements stay in the browser through local storage.

## Sources and scope

Object status, dimensions, and distribution are taken from publisher, exhibition, and collector-catalog records where available. The gallery links each object back to its record. Secondary listings are used as evidence that a physical object survives, not as authority for the underlying artwork.

This is an independent archival study and is not affiliated with Takehiko Inoue, IT Planning, Kodansha, or the exhibition organizers.
